## 🧩 快速查表

### 什么时候用哪种数据结构
| 需求 | 用 Go 的做法 |
|------|-------------|
| 数组 / 动态列表 | 切片 `[]T` |
| 哈希表 | `map[K]V` |
| 集合（去重） | `map[T]struct{}` |
| 栈 | `append` + `stack[:n-1]` |
| 队列 | `append` + `queue[1:]` |
| 有序表 | `sort` + 切片 |

### 一句话记忆
- **判存在** → `_, ok := m[k]`
- **取子段** → 左闭右开 `s[i:j]`，`[:len-1]` 排除最后一个
- **字符串按字符** → `[]rune(s)`，`len(rs)` 才是字符数
- **排序** → `sort.Slice(s, func(i, j int) bool {...})`
- **栈/队列** → 切片头部/尾部进出，判空用 `len(x) == 0`
- **位运算** → `n & 1` 判奇偶、`n & (n-1)` 去最低位1
