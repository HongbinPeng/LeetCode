# Go 位运算（刷算法速查）

> 处理**数字的二进制位**，常用于**去重、判奇偶、集合表示、加快运算**。Go 操作符和 C/Java 相似，但多了 `&^` 且 `^` 兼具取反功能。

---

## 一、操作符速查

| 操作符 | 含义 | 说明 |
|--------|------|------|
| `&` | 与 AND | 两位都 1 才得 1 |
| `\|` | 或 OR | 任一为 1 就得 1 |
| `^` | 异或 XOR | 不同为 1 |
| `&^` | 位清空 AND NOT | `a &^ b`，b 中为 1 的位在 a 里清 0 |
| `<<` | 左移 | 低位补 0，`a << n` 相当于 `a * 2^n` |
| `>>` | 右移 | 无符号补 0，`a >> n` 相当于 `a / 2^n` |
| `^`（一元） | 按位取反 | `^a`，不是 `~a` |

```go
a := 0b1010   // 10
b := 0b1100   // 12

a & b          // 0b1000 = 8
a | b          // 0b1110 = 14
a ^ b          // 0b0110 = 6
a &^ b         // 0b0010 = 2
a << 2         // 40
a >> 2         // 2
^a             // 按位取反（注意是一元 ^）
```

> **和 Java 的区别**：Java 取反是 `~`，Go 是一元 `^`；Go 还多了位清空 `&^`。

## 二、高频技巧（必须背熟）

### 1. 判断奇偶
```go
if n&1 == 1 {        // 奇数
} else {             // 偶数
}
// 比 n%2 更快
```

### 2. 获取 / 清除低位
```go
n & 1            // 取最低位（第 0 位）
n & (1 << k)     // 判断第 k 位是否为 1
n | (1 << k)     // 把第 k 位置 1
n &^ (1 << k)    // 把第 k 位清 0
n ^ (1 << k)     // 翻转第 k 位
```

### 3. 去掉最低位的 1（超级好用）
```go
n & (n - 1)      // 例：0b1010 → 0b1000，去掉二进制最后一位 1
```
> 用途：**统计 1 的个数**（每次去掉一个直到 0）、**判断 2 的幂**（`n & (n-1) == 0`）。

### 4. 位运算做集合
用 int 的每一位表示一个元素在不在集合里（元素量 ≤ 64）。

```go
// 比如状态集合：第 i 位表示元素 i 是否出现
set := 0
set |= 1 << 3        // 加入元素 3
set |= 1 << 5        // 加入元素 5

if set&(1<<3) != 0 { // 判断 3 在不在
}
// 一个 int 当 64 位的 bool 数组用
```

## 三、刷题高频题型的套路

### 1. 找出只出现一次的数（异或）
> 异或性质：`a^a=0`、`a^0=a`、交换律结合律。
> 数组中一个数出现 1 次，其余出现 2 次：
```go
func singleNumber(nums []int) int {
    res := 0
    for _, n := range nums {
        res ^= n        // 成对的会相互抵消，只剩只出现一次的
    }
    return res
}
```

### 2. 统计二进制里 1 的个数
```go
func countBits(n int) int {
    count := 0
    for n > 0 {
        n = n & (n - 1)   // 每次去掉一个 1
        count++
    }
    return count
}
```

### 3. 判断 2 的幂
```go
func isPowerOfTwo(n int) bool {
    return n > 0 && n&(n-1) == 0
}
```

### 4. 交换两个数（不用临时变量）
```go
a, b = b, a       // Go 直接这么写就行，不需要异或
// 或用异或：
a ^= b; b ^= a; a ^= b
```

## 四、易错陷阱

| 场景 | 坑 |
|------|-----|
| 取反是 `^a` | 不是 `~a`（那是 Java） |
| 移位优先级 | `<<`/`>>` 优先级低于 `+`，加括号 `(a + b) << 2` |
| 右移补位 | 无符号右移补 0；**负数/有符号右移**会补符号位（Go 的 int 是算数右移） |
| 溢出 | `1 << 31` 在 32 位 int 会溢出，用 `1 << 30` 或 `int64` |
| 负数位运算 | 负数用补码表示，`-1` 全为 1（`^0` 即 `-1`） |

## 五、刷题参考模板

```go
// 枚举集合（位掩码遍历所有子集）—— 状态压缩/DP 常用
n := len(arr)
for mask := 0; mask < (1 << n); mask++ {
    // 检查第 i 位是否选中
    for i := 0; i < n; i++ {
        if mask&(1<<i) != 0 {
            // 元素 i 在子集里
        }
    }
}
```

## 汇总：最常用的 6 个位运算式子

| 式子 | 作用 |
|------|------|
| `n & 1` | 判奇偶 |
| `n & (n-1)` | 去掉最低位 1 |
| `n & (n-1) == 0` | 判 2 的幂 |
| `1 << k` | 第 k 位置 1 / 当掩码 |
| `a ^ b` | 异或、找唯一出现一次 |
| `set \| (1 << k)` | 集合加入元素 |
