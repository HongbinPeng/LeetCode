# Go 栈和队列（刷算法速查）

> Go **没有内置的 Stack / Queue 类**（不像 Java 的 `Deque`）。刷题一律用**切片 `[]T` 模拟**，理解起来其实跟 Java/C++ 一样。

---

## 一、栈（Stack，后进先出 LIFO）

用切片在**末尾**增删，最方便。

```go
stack := []int{}

// 入栈 push
stack = append(stack, 1)
stack = append(stack, 2)

// 看栈顶 peek（不删）
top := stack[len(stack)-1]

// 出栈 pop（先取再删）
x := stack[len(stack)-1]
stack = stack[:len(stack)-1]

// 判空
len(stack) == 0
```

> 对应 Java：`stack.push(x)` / `stack.peek()` / `stack.pop()`。

---

## 二、队列（Queue，先进先出 FIFO）

用切片在**头部出、尾部进**。

```go
queue := []int{}

// 入队 enqueue
queue = append(queue, 1)
queue = append(queue, 2)

// 看队头 peek
front := queue[0]

// 出队 dequeue（先取再删头）
x := queue[0]
queue = queue[1:]

// 判空
len(queue) == 0
```

> 对应 Java：`queue.add(x)` / `queue.peek()` / `queue.poll()`。

---

## 三、双端队列（Deque）

**两边都能增删**。用两个指针或干脆管理一个切片。

```go
deque := []int{}

// 头插
deque = append([]int{0}, deque...)

// 尾插
deque = append(deque, 3)

// 头删
deque = deque[1:]

// 尾删
deque = deque[:len(deque)-1]
```

> `append([]int{0}, deque...)` 每次头插都是 O(N)，性能差。真正的高频双端队列场景（如单调队列）不推荐用它，见下方「单调队列」。

## 四、刷题高频应用

### 1. 有效括号（栈经典）
```go
func isValid(s string) bool {
    stack := []rune{}
    for _, c := range s {
        switch c {
        case '(', '[', '{':
            stack = append(stack, c)
        case ')', ']', '}':
            if len(stack) == 0 {
                return false
            }
            top := stack[len(stack)-1]
            if (c == ')' && top != '(') ||
               (c == ']' && top != '[') ||
               (c == '}' && top != '{') {
                return false
            }
            stack = stack[:len(stack)-1]
        }
    }
    return len(stack) == 0
}
```

### 2. BFS 层序遍历（队列经典，树的题）
```go
func levelOrder(root *TreeNode) [][]int {
    res := [][]int{}
    if root == nil {
        return res
    }
    queue := []*TreeNode{root}
    for len(queue) > 0 {
        n := len(queue)
        level := []int{}
        for i := 0; i < n; i++ {
            node := queue[0]
            queue = queue[1:]
            level = append(level, node.Val)
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }
        res = append(res, level)
    }
    return res
}
```

### 3. DFS 栈模拟（树的题，替代递归）
```go
stack := []*TreeNode{root}
for len(stack) > 0 {
    node := stack[len(stack)-1]
    stack = stack[:len(stack)-1]
    // 处理 node ...
    if node.Right != nil {
        stack = append(stack, node.Right)
    }
    if node.Left != nil {
        stack = append(stack, node.Left)
    }
}
```

### 4. 单调栈（下一个更大元素）
```go
// 找每个元素右边第一个比它大的
func nextGreater(nums []int) []int {
    res := make([]int, len(nums))
    for i := range res {
        res[i] = -1
    }
    stack := []int{}              // 存下标
    for i, n := range nums {
        for len(stack) > 0 && nums[stack[len(stack)-1]] < n {
            res[stack[len(stack)-1]] = n
            stack = stack[:len(stack)-1]   // 出栈
        }
        stack = append(stack, i)   // 入栈
    }
    return res
}
```

## 五、性能优化提示

### 出队频繁时的坑（`queue[1:]`）
每次 `queue[1:]` 会让切片起点后移，**底层数组不断前移**，大量出队时反而慢。改进法：

**用下标指针，不真正删元素**：
```go
queue := []int{...}
i := 0
for i < len(queue) {
    x := queue[i]
    i++                 // 用指针移动代替 queue = queue[1:]
    // 处理 x ...
}
```

> 二叉树 BFS 层序那种「一次处理一层」的场景，用 `n := len(queue)` 快照长度即可，天然避免逐个出队问题。

## 六、刷题快速对照

| 需求 | Java | Go 写法 |
|------|------|---------|
| 栈 | `Deque` | `append` 入栈 / `stack[:n-1]` 出栈 |
| 队列 | `Deque` | `append` 入队 / `queue[1:]` 出队 |
| 队头 peek | `peek()` | `queue[0]` |
| 栈顶 peek | `peek()` | `stack[n-1]` |
| 判空 | `isEmpty()` | `len(x) == 0` |
| 双向队列 | `ArrayDeque` | 切片手动头插尾插（低频才用） |

> 核心就一句话：**栈 = 切片尾部进出；队列 = 尾部进、头部出；判空 = `len == 0`**。
